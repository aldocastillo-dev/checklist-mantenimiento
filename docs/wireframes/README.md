# Wireframes de ReporteMtto
Flujo principal: P1 Nuevo checklist → P2 Detalle realizado y horas → P3 Firma → P4 Confirmación. P5 es la bandeja del programador. Cada imagen trae sus cuatro notas.

Los recuadros de P1, P2 y P3 son los del «Check list entrega trabajos de mantenimiento» que ya autorizó el mandante: la app completa esa misma hoja.
